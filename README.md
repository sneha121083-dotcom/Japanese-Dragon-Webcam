# Japanese Dragon Webcam 🐉

An interactive Japanese dragon experience controlled using hand gestures captured through a webcam.

## ✨ Features

- Interactive dragon experience using webcam input.
- Hand-gesture-based controls.
- Real-time visual interaction.
- Browser-based interface.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Webcam access through the browser

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed.
- A webcam.
- A modern web browser.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sneha121083-dotcom/Japanese-Dragon-Webcam.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Japanese-Dragon-Webcam/japanese-dragon-webcam
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🎮 How to Use

1. Start the application.
2. Allow webcam access if requested.
3. Try the supported hand gestures to interact with the dragon.
